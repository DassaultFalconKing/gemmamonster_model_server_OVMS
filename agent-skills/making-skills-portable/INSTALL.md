# Installation

This directory is self-contained.

Cross-platform:

```bash
python install.py
python install.py "$HOME/.claude/skills"
```

POSIX shell:

```bash
sh install.sh
sh install.sh "$HOME/.claude/skills"
```

PowerShell:

```powershell
.\install.ps1
.\install.ps1 -TargetRoot "$HOME/.claude/skills"
```

Default target root: `~/.agents/skills`.
